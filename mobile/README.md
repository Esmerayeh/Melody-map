# Melody Map Mobile Scaffold

This is a lightweight Expo scaffold that mirrors the current Melody Map backend contract without rebuilding the full product.

## Run

```bash
cd mobile
npm install
npm run start
```

## Included screens

- Login
- Home
- Identity
- Soul Orb placeholder
- Discover
- Soulmates

## Notes

- `src/services/api.js` points at the existing Melody Map backend.
- Auth is currently a placeholder screen so the scaffold stays non-breaking.
- The goal is to let the product expand into mobile without changing the current web routes.
